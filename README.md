#  ABC Books Website

ABC Books is a simple book website built with Next.js.  
Users can explore books, view details, and enjoy a clean reading experience.

 # Features
 Home page with banner and top books
 All books listing page
 User authentication (Login / Signup)
  Google Sign-in support
 User profile with avatar
 Protected routes
 Responsive design

# Tech Stack
 Next.js
 React
 Tailwind CSS
 MongoDB
 Better Auth
 HeroUI
